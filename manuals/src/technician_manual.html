Build the Serialine package

On a UMS PC with Python installed:

  1. Put serialine.py, printer_settings.txt and build_exe.bat in one folder.
  2. Double-click build_exe.bat and wait until it shows Done (1–3 minutes).
  3. Check the new folder Serialine_Package contains Serialine.exe and printer_settings.txt.
  4. Edit printer_settings.txt with the client's printer IP, then copy Serialine_Package to the USB stick.

05
Printer

Print job setup

The job needs one text field that takes its text from the mailing queue. Without it, the printer accepts the serials but prints nothing from them.

  1. Stop printing and open the client's job in the job editor (or create a new job).
  2. Add or select the text object for the serial.
  3. Set its text source to Extern Text in mailing mode (may be called Mailing, Database or Mail field), field number 1.
  4. Set the length to at least the longest serial. Recorded length: ________
  5. Set font, position and orientation as the client requires. Other fixed text, dates or logos in the job are fine.
  6. Job parameters: PrintGo source = External (photo-eye), edge as wired; PrintGo repetition = 0.
  7. Set the print delay so the serial lands in the right place on the product.
  8. Save the job, then load it again.
Check

The connection test (chapter 06) must show a line like *EXTTXT [ 12 (X) 1 0 0 0 0 0]. The third value must be 1 (mailing field 1); the first value is the length. A 0 in third place means Extern Text mode – fix step 3.

06
Client PC

Client PC setup

  1. Copy. Copy Serialine_Package to the client PC, e.g. C:\Serialine or the Desktop, and rename the folder to Serialine.
  2. Network. Connect the PC to the printer's network. In Command Prompt run ping <printer IP>. Replies = OK.
  3. No replies?
    • Direct cable: Settings → Network & internet → Ethernet → IP assignment → Edit → Manual → IPv4. Use an address in the printer's range, e.g. 192.168.1.50, subnet 255.255.255.0, no gateway.
    • Client network: ask client IT for the printer's reachable IP and put it in printer_settings.txt.
  4. Power. Settings → System → Power → Screen and sleep: sleep when plugged in = Never.
  5. Antivirus / SmartScreen. Serialine.exe is not code-signed. On "Windows protected your PC" click More info → Run anyway. If antivirus quarantines it, ask client IT to allow it, or use the fallback (chapter 10).
  6. Connection test. Double-click Serialine.exe, type T, press ENTER. All six pass criteria below must show.
  7. Shortcut. Right-click Serialine.exe → Show more options → Send to → Desktop (create shortcut). Rename it "Serialine".

Commissioning and sign-off

Commissioning passes when every box is ticked. Keep the signed page with the job card.

Test A – 5 products

File Test5.csv; printer ready, printing stopped.

  • Shows 5 serial(s) queued ... (records 1..5)
  • Products 1–5 get TEST0001–TEST0005 in order
  • [SUCCESS] and the printer stops by itself
  • A 6th product after the stop gets no print
  • Test5_log.csv lists the 5 serials
  • Print position, size and legibility approved

Test B – line speed

50-serial file at normal production speed.

  • All 50 printed in order, no gaps, no duplicates
  • No printer errors during the run
  • Products per minute: ________

Test C – stop and resume

  • Stop mid-batch shows [STOPPED] ... record X
  • After ENTER, printing resumes at X+1

Test D – reprint

  • Finished file offers reprint; YES reprints; old log kept

Handover

Handover and operator training

Train every operator who will run batches, and let each one run a test batch themselves.

  • Fill in the Support page of the User Manual (technician, install date, printer serial, printer IP) and hand it over
  • Show how to prepare a serial file: column A, from A1, no heading, unique serials
  • Operator starts a batch alone: printer ready → double-click Serialine → choose file → check N → ENTER
  • Show a stop and resume
  • Show where the logs are and explain they must be kept
  • Explain reprints: remove the first-run products first, then y and YES
  • Explain the blank product that can occur at the end of a batch
  • Agree who backs up the Serialine folder, and where

Fallback

If the .exe is blocked: install Python 3 from python.org for the current user (tick "Add python.exe to PATH"). Copy serialine.py, requirements.txt and printer_settings.txt into the Serialine folder and run pip install -r requirements.txt there. Double-click serialine.py, or use the commands above with python serialine.py in place of Serialine.exe.

Under the hood

How Serialine talks to the printer

Serialine uses the printer's mailing mode (Leibinger Interface Protocol v1.9.15, Annex B). Every message is ^0 + command + carriage return, over TCP port 3000.

CommandPurpose in Serialine
?VSFirmware version (connection test)
?RSMachine state (5 = ready, 6 = printing) and error number
?SMMailing queue: depth, entries, last printed record number
?JB / ?JLLoaded job script / name (checks the EXTTXT field)
!FFClear the mailing queue before loading a batch
=CM<n>Stop after record n (ignored by JET2neo V75.0.11.2)
=MR<n><TAB><serial>Queue serial as record n
!GO / !STStart / stop printing

Sequence per batch

  1. Wait for state 5 (ready); clear the queue (!FF).
  2. Send up to 255 records (=MR), numbered 1, 2, 3 … in file order.
  3. Operator presses ENTER → !GO. Each PrintGo prints the next record; the printer rejects gaps and repeats.
  4. Every 0.2 s Serialine reads ?SM, logs newly printed records and tops up the queue in blocks of 50. The queue is a rolling buffer, so batch size is unlimited (tested with 12,000 serials in one run).
  5. A blank end-marker record follows the last serial so the queue never runs empty (JET2neo error 5043). When the last serial is reported printed, Serialine sends !ST.
  6. If printing stops early, the printer clears its queue; Serialine reloads from the first unprinted record.
